            Connection & sign-in

            Copilot Studio has retired the Direct Line token endpoint for new agents and replaced it with a Microsoft 365 Agents SDK connection string. BIG A now speaks that protocol directly, which is what keeps messages copyable, styled, stored and droppable. The older Direct Line, single sign-on and embed modes are still here as fallbacks.

            Copilot Studio › your agent › Channels › Web app or Native app › Microsoft 365 Agents SDK. Pasting it fills in the boxes below.

            Both are in Copilot Studio › Settings › Advanced › Metadata.

            Only needed if your connection string supplies a full endpoint. It overrides the environment ID and schema name above.

            Copilot Studio › your agent › Channels › Mobile app. New agents no longer show this — if yours does not, use the Agents SDK mode instead.

            Leave as common to allow any Microsoft account. The Agents SDK works best with your own tenant ID.

            For the Agents SDK, leave the default https://api.powerplatform.com/CopilotStudio.Copilots.Invoke. For legacy single sign-on, use the scope exposed by your authentication app registration.

            How to set up the Microsoft 365 Agents SDK connection
            1. In Copilot Studio, open your agent › Channels › Web app (or Native app) and copy the Microsoft 365 Agents SDK connection details.
            2. In the Azure portal, register an application. Under Authentication, add a Single-page application platform with this exact redirect URI: —
            3. Under API permissions, add Power Platform API › Delegated › CopilotStudio.Copilots.Invoke, then grant admin consent. If Power Platform API is not listed, register the Microsoft.PowerPlatform resource provider in your tenant first.
            4. Paste the client ID and tenant ID above, sign in, then use Test connection.
            5. Publish your agent. The Agents SDK talks to the published agent, so unpublished changes will not appear.

            Users of this page need access to the agent in Copilot Studio. There is no anonymous mode: every request carries a signed-in user's token.

            How to set up legacy single sign-on

            SSO needs two separate Entra app registrations. Reusing one for both will not work.

            1. Authentication app — in Copilot Studio open Settings › Security › Authentication, choose Authenticate manually with Microsoft Entra ID V2, and follow the wizard to register it. Note that Authenticate with Microsoft will not work here — that option only supports the Teams channel.
            2. Canvas app — register a second application. Under Authentication, add a Single-page application platform with this exact redirect URI: —
            3. In the authentication app, go to Expose an API, add a scope, and copy its full value into the Custom scope box above.
            4. Still in Expose an API, under Authorized client applications, add the canvas app's client ID.
            5. Back in Copilot Studio's Authentication panel, paste that same scope into Token exchange URL and save.
            6. Grant admin consent on both registrations, then publish your agent — auth changes only take effect after publishing.
