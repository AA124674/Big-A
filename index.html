      Welcome to BIG A

      A private front end for your Copilot Studio agents. Conversations are rendered and stored by this page, so they stay copyable, themeable and yours. Add an agent to begin.

      1. Publish your agent In Copilot Studio, publish the agent at least once. An unpublished agent cannot accept connections.
      2. Copy its connection details Open the agent and go to its Channels page, then Web app or Native app, and copy the connection string shown under Microsoft 365 Agents SDK. If you cannot find Channels, Settings → Advanced → Metadata lists the Environment ID, Tenant ID and Schema name, which work just as well.
      3. Paste it here Open Connection settings and paste it into the first box. The environment and schema name are worked out for you.

      No agent to hand? You can still explore the interface — the sidebar, workbench and command palette (Ctrl / Cmd + K) all work without a connection.

            Connection & sign-in

            1 Point this page at your agent Required. Paste once and the boxes below fill themselves in.

            Prefer the complete Microsoft 365 Agents SDK connection string from the agent’s Channels page. A direct-connect URL, embed code, web chat address, or Session details block can also be read, but may not contain every value needed to connect.

            If entering values by hand, use the schema name from Settings › Advanced › Metadata and copy Environment ID from Power Apps › Settings › Developer resources. For the default environment, preserve the complete Default-… value; the prefix is required.

            1 Add your Anthropic API key Required. Requests go straight from this browser to api.anthropic.com — there is no server in between, so nothing but your messages ever leaves this device.

            Create a key at console.anthropic.com › Settings › API keys. Anyone with access to this browser can read the key back out of its network requests, so use one scoped to a low spending limit rather than a personal or organisation-wide key.

            Any current model works here. Choose Custom model ID to type one that is not listed yet — a new release, or an older snapshot to pin.

            How to set up legacy single sign-on

            SSO needs two separate Entra app registrations. Reusing one for both will not work.

            1. Authentication app — in Copilot Studio open Settings › Security › Authentication, choose Authenticate manually with Microsoft Entra ID V2, and follow the wizard to register it. Note that Authenticate with Microsoft will not work here — that option only supports the Teams channel.
            2. Canvas app — register a second application. Under Authentication, add a Single-page application platform with this exact redirect URI: —
            3. In the authentication app, go to Expose an API, add a scope, and copy its full value into the Sign-in scope box above.
            4. Still in Expose an API, under Authorized client applications, add the canvas app's client ID.
            5. Back in Copilot Studio's Authentication panel, paste that same scope into Token exchange URL and save.
            6. Grant admin consent on both registrations, then publish your agent — auth changes only take effect after publishing.

            These details are stored only in this browser. Authenticated modes load Microsoft's sign-in library from Microsoft's own CDN.
